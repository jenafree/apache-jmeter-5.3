Documentação - Teste de Performance
Este documento fornece instruções para executar o script de teste de performance do projeto usando o Apache JMeter. O objetivo deste teste é verificar o desempenho do cenário de compra de passagem aérea no site "https://www.blazedemo.com", atendendo aos critérios de aceitação de uma vazão de 250 requisições por segundo e um tempo de resposta 90th percentil inferior a 2 segundos.

Pré-requisitos
Antes de executar o teste, verifique se você tem os seguintes pré-requisitos instalados em seu ambiente:

Apache JMeter (versão 5.0.1 ou superior): O JMeter é uma ferramenta de teste de desempenho e carga de código aberto amplamente utilizada.

Configuração do Teste
Siga as etapas abaixo para configurar e executar o teste de desempenho:

Baixe e instale o Apache JMeter, se ainda não o tiver feito.

Baixe o arquivo de script de teste fornecido neste projeto.

Abra o Apache JMeter e abra o arquivo de script de teste baixado.

No painel de árvore à esquerda, localize o elemento "Thread Group" e clique com o botão direito do mouse nele. 
Selecione "Config Element" -> "HTTP Request Defaults" no menu suspenso.
No painel de propriedades à direita, atualize o valor da variável "Server Name or IP" para "https://www.blazedemo.com".

Salve as alterações no arquivo do script de teste.

Executando o Teste
Agora você está pronto para executar o teste de desempenho. 
Siga as etapas abaixo:

No Apache JMeter, clique em "Run" na barra de menu superior e selecione "Start" ou pressione o atalho de teclado "Ctrl+R".

O teste de desempenho será iniciado e você poderá acompanhar o progresso no painel de resultados em tempo real.

Aguarde até que o teste seja concluído. Os resultados serão coletados e exibidos no painel de resultados.

Após a conclusão do teste, você pode analisar os resultados para verificar se os critérios de aceitação foram atendidos.

Analisando os Resultados
O Apache JMeter fornece várias ferramentas de análise de resultados para ajudá-lo a interpretar os dados coletados durante o teste de desempenho. Aqui estão algumas das ferramentas mais comuns:

Summary Report: Exibe um resumo dos resultados, incluindo tempos de resposta, taxa de transferência e erros.

View Results Tree: Mostra os resultados detalhados de cada requisição, permitindo visualizar os tempos de resposta individuais e os dados da resposta.

Graph Results: Exibe gráficos de desempenho, como tempos de resposta ao longo do tempo, taxa de transferência e outras métricas.

View Results in Table: Apresenta uma tabela com os resultados completos, permitindo classificar e filtrar com base em diferentes métricas.
